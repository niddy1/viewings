If you find the film's title logo, save it as the file named below and Claude will put it on the spine with `Pic(...)` and take the line off this list.

Any image works: a transparent PNG is best; a logo on black is fine too (it gets keyed out, but then only suits a dark spine). Higher resolution is better.
